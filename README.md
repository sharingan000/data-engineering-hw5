# ДЗ 5 · Управление ресурсами
Локальная проверка: `python3 worker.py single` и `python3 worker.py local`.
Для эксперимента нужны запущенный Docker Engine, kind, kubectl, Python 3, доступ к реестрам образов, свободное имя кластера de-hw5 и минимум 4 CPU у Docker VM. Запуск из этой папки: `bash run.sh`. Скрипт создаёт отдельный одноузловой кластер, сохраняет события и результаты в logs и оставляет кластер для проверки. Для измерения нужен cgroup v2 с доступным memory.peak. Для удаления созданного стенда после проверки: `kind delete cluster --name de-hw5`.

В data находятся канонический файл ДЗ 3 и эталон первых десяти пар из artifacts/frequencies.json того задания. pipeline.py скопирован из ДЗ 3. Происхождение данных описано в DATA_SOURCES.md (пути в этом документе относятся к ДЗ 3).
